# System Silence (Do not open.)

**System Silence** è un'installazione web interattiva e concettuale che esplora il sovraccarico mentale e l'uso dell'architettura logica come meccanismo di difesa emotiva. Attraverso un'estetica minimale e telemetrica, la piattaforma permette all'utente di alternare la complessità delle strutture dinamiche a uno stato di totale silenzio e presenza.

---

## 🛠️ Tech Stack

* **Framework:** React + TypeScript + Vite
* **3D & Graphics:** `@react-three/fiber`, `@react-three/drei`, `three`
* **Animations:** `framer-motion`
* **Icons & Styling:** `lucide-react`, Tailwind CSS

---

## 🚀 Getting Started

### Prerequisites

* Node.js (v18+ raccomandato)
* npm / pnpm / yarn

### Installation

1. **Clona la repository:**
```bash
git clone https://github.com/your-username/system-silence.git
cd system-silence

```


2. **Installa le dipendenze:**
```bash
npm install

```


3. **Avvia il server di sviluppo:**
```bash
npm run dev

```


4. Apri il browser all'indirizzo `http://localhost:5173`.

---

## ⚙️ Build for Production

Per compilare il progetto e generare i file statici pronti per la produzione:

```bash
npm run build

```

Per testare la build in locale:

```bash
npm run preview

```

---

## 🎨 Concept Architecture

* **Noise Mode (`ACTIVE_STRUCTURE`):** Rappresenta la mente iper-attiva, la modellazione continua e il bisogno di strutturare informazioni complesse.
* **Quiet Mode (`REST`):** Disattiva i loop di calcolo e riduce la rete neurale a un segnale minimo, forzando la pausa e l'assenza di compiti da risolvere.
